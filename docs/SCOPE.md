# 확정 범위와 Docs 대응

기준: [Notion 프로젝트 및 Docs](https://app.notion.com/p/41112d572453805a9123c43dac79a063), Docs 기능 명세 P0·P1, 이후 사용자와 합의한 아래 정책. P2는 구현 범위에서 제외합니다. 대회 안내는 [Pleos App Developer Challenge](https://appdevchallenge.auto-hmg.io/)입니다.

## 합의한 제품 정책

| 항목 | 확정 내용 |
|---|---|
| 서버 | Spring Boot + Java, PostgreSQL, REST, 우선 로컬 검증 |
| 기업 가입 | 기업과 대표 관리자 OWNER 1명을 함께 생성 |
| 직원 관리자 | OWNER가 계정 발급·비활성화. STAFF는 차량·운전자·운행·승인·보고서 관리 |
| 로그인 | 관리자마다 이메일 + 비밀번호 |
| 최초 비밀번호 | 대표가 일회용 설정 링크를 받아 직접 전달 |
| 운전자 | 차량에서 등록된 이름 선택. 운전자 로그인/PIN 없음 |
| 동기화 | 운전자 확인 전의 진행 중·미완료·미확인 기록도 업로드 |
| 승인 | 운전자 확인 → 관리자 승인 → 보고서 반영 |
| 수정 | 승인 후 수정하면 보고서 제외 및 재승인 대기. 운전자가 바뀌면 새 운전자 확인도 필요 |
| 추천 | 해당 운전자의 최근 확인 기록에 나온 목적·거래처 후보, 자동 확정 없음 |
| 배포 | 이번 작업은 로컬 기준. 클라우드·운영 배포 결정 유보 |
| 협업 | Conventional Commits와 PR 제목 `feat: 한국어 설명`, `chore: 한국어 설명` 등 |

## 구현 기본값과 아직 확정하지 않은 영역

다음은 동작 가능한 로컬 구현을 위한 설정값이며 제품에서 새로 확정한 정책으로 간주하지 않습니다.

- 관리자 토큰 12시간, 차량 토큰 90일, 직원 설정 링크 24시간, 페어링 토큰 10분. 환경 설정으로 변경할 수 있습니다.
- 차량은 한 번에 유효한 연결 토큰 한 개를 사용합니다. 재연결 시 이전 토큰을 폐기합니다. 만료된 차량은 관리자에게 새 페어링 토큰을 받아 재연결합니다.
- 보고서 월은 KST 운행 시작일에 귀속합니다. 자정을 넘는 한 구간을 거리 비례로 나누지 않습니다.
- 0인 시작 계기판 값은 에뮬레이터 초기값 가능성이 있어 검토 대상으로 보존하며 승인하지 않습니다. 실제 차량의 0km 허용 등 정책은 확인 후 바꿉니다.
- 동의 이벤트는 선택된 운전자와 차량이 보낸 입력의 이력입니다. 이름 선택만으로 실제 인물을 인증하지 않습니다.
- Docs에 따라 국세청 초안의 사용자 칸을 운전자 이름·부서 스냅샷으로 미리 채웁니다. 실제 차량 사용자가 다르면 제출 전 수정해야 한다는 안내를 표시합니다.
- 서버가 지원하는 SDK 입력 계약과 실제 차량에서 제공되는 필드·시동 종료 이벤트는 별개입니다. 실차 동작을 검증했다고 주장하지 않습니다.

위치/경로, 실비 정산, GPS 기반 목적 추론, 실차 원격 제어, 메일 발송, 운영 배포와 관측 도구는 포함하지 않습니다. 기존 데이터의 물리 삭제와 회사 소유권 이전도 API로 제공하지 않습니다.
