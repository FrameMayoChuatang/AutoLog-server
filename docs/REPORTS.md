# 통계와 엑셀 출력 기준

`GET /api/statistics?month=2026-10`, `GET /api/reports/monthly.xlsx?month=2026-10`, `GET /api/reports/nts-draft.xlsx?month=2026-10`을 제공합니다. 선택한 `vehicleId`를 추가하면 한 차량만 조회합니다. 회사는 인증 토큰에서 결정합니다.

## 공통 기준

- 월은 `Asia/Seoul`의 월 시작 이상, 다음 월 시작 미만인 **운행 시작 시각**으로 선택합니다. 자정이나 월 경계를 넘은 운행은 시작 월에 통째로 귀속합니다.
- XLSX 본표와 승인 거리에는 정상 완료·정상 측정값·운전자 확인·관리자 승인을 모두 충족한 기록만 포함합니다.
- 승인 후 편집하면 새로 출력하는 본표에서 즉시 제외됩니다. 이미 내려받은 파일은 그때의 스냅샷입니다.
- 다운로드와 통계는 각각 반복 읽기 트랜잭션으로 생성하여 한 결과 안에서 서로 다른 시점의 상태를 섞지 않습니다.
- 빈 결과도 헤더와 안내가 있는 유효한 XLSX로 반환합니다. 출력은 최대 50,000건이며 DB 조회도 50,001건에서 제한하여 초과 여부를 먼저 검사합니다.
- 모든 사용자 입력은 엑셀 문자열 셀로 작성합니다. `=`, `+`, `@` 등으로 시작해도 수식으로 실행하지 않습니다.

## 통계 필드

| 필드 | 의미 |
|---|---|
| knownCompletedKm | 승인 여부와 무관하게 정상 종료·측정값이 있는 거리 |
| approvedKm | 출력 가능한 승인 거리 합계 |
| approvedCommuteKm / approvedBusinessKm / approvedPersonalKm | 승인된 출퇴근 / 일반 업무 / 개인 거리 |
| unreviewedKnownKm | knownCompletedKm - approvedKm. 업무 거리로 간주하지 않음 |
| unconfirmedKnownKm | 운전자 확인이 없는 정상 종료 거리. 보완 요청 거리 포함 |
| pendingApprovalKm | 운전자 확인 후 관리자 승인 대기 중인 정상 종료 거리 |
| changesRequestedKm | 보완 요청 중인 정상 종료 거리. unconfirmedKnownKm의 부분집합이므로 중복 합산하지 않음 |
| incompleteObservedKm | 미완료 기록에서 시작값과 마지막 관측값으로 계산 가능한 거리. 최종 거리에 합산하지 않음 |
| approvedRecordBusinessRatioPercent | 승인 기록 중 `(출퇴근+일반업무)/승인거리 × 100`. 분모 0이면 null. 세무상 연간 최종 비율이 아님 |
| incompleteCount / unconfirmedCount / measurementIssueCount | 미완료 / 운전자 미확인 / 완료됐으나 측정 오류가 있는 건수. 서로 겹칠 수 있음 |
| pendingApprovalCount / changesRequestedCount | 승인 대기 / 보완 요청 건수 |
| gaps | 아래 기준의 확인된 공백과 판단 불가 경계 |
| vehicles | 기록 없는 등록 차량도 포함한 차량별 운행일수·분류별 거리·월말 근거·보고사항 |

## 기록 간 공백

차량별 시간순으로 이전 기록의 종료 계기판과 다음 기록의 시작 계기판을 비교합니다. 조회 월 직전 기록도 비교에 사용합니다. 정상 완료된 이전 기록과 겹치지 않는 다음 기록의 차이가 양수면 `GAP_DETECTED`이며 `knownGapKm`에 합산합니다.

첫 기록 이전이나 마지막 기록 이후에 얼마를 주행했는지는 서버가 알 수 없습니다. 이전 기록이 없거나 미완료, 계기판 누락·역전, 이전 기록의 측정 오류, 바로 이전뿐 아니라 더 앞선 기록과의 시간 중첩이면 `distanceKm=null`로 남깁니다. 확인 가능한 공백도 업무 거리로 자동 분류하지 않습니다. 합계 0이 모든 누락이 없다는 뜻은 아닙니다.

## 월간 XLSX

`안내`, `승인 운행기록`, `승인 거리 집계`, `차량별 월간 집계`, `검토 필요 기록`, `기록 간 공백` 시트를 생성합니다. 승인 기록에는 운행 ID, 차량, 시각, 운전자 스냅샷, 분류, 계기판 전후/거리, 목적, 거래처, 비고, 승인 시각이 들어갑니다. 미확인·미완료·보완 요청·승인 대기 기록은 검토 시트로 분리합니다.

## 국세청 서식 초안

출처는 [국세청고시 제2025-8호 「업무용승용차 운행기록 방법에 관한 고시(법인세법)」](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?mi=2205&nttSn=1341754)의 2025-04-01 별지 서식입니다. 서버 양식 버전은 `autolog-nts-2025-8-v2`입니다. 공식 HWPX를 그대로 복제한 파일은 아니며, 필요한 항목을 대응한 XLSX 초안입니다.

| 공식 필드 | 출력 |
|---|---|
| 법인명 | 기업 가입 이름 |
| 사업자등록번호·사업연도 | 미정이므로 빈칸 |
| ① 차종·② 자동차등록번호 | 현재 차량 정보. 이전 정보와 다르면 검토 |
| ③ 사용일자 | KST 운행 시작일과 요일 |
| ④ 사용자 부서·성명 | Docs 요구대로 확인된 운전자 스냅샷을 미리 채움. 실제 사용자가 다른 경우 제출 전 수정 |
| ⑤·⑥ 계기판 전후·⑦ 주행거리 | 승인 기록의 원본 계기판 값과 차이 |
| ⑧ 출퇴근용·⑨ 일반 업무용 | 각각 해당 분류의 승인 거리 |
| ⑩ 비고 | 분류·목적·비고 |
| ⑪·⑫·⑬ 사업연도 합계와 비율 | 빈칸. 선택 월 승인 합계를 연간 총계로 대체하지 않음 |
| 추가 참고 열 | 운전자 부서·이름, 운행 ID, 거래처 |

차량별 시트에 선택 월 승인 소계를 별도로 제공합니다. 실제 사용자, 사업자등록번호, 사업연도, 누락 기록, 연간 합계를 확인한 뒤 사용해야 합니다. 세무상 비용 인정이나 신고 완료를 자동 보증하는 기능은 아닙니다.

## 차량별 운행일수와 월말 기준값

월간 양식 버전은 `autolog-monthly-v2`입니다. 두 XLSX 모두 `차량별 월간 집계`를 포함합니다.

- `approvedDrivingDays`: 승인 기록의 서로 다른 KST **시작일** 수. 한 날 여러 운행은 1일입니다.
- `approvedDurationSeconds`: 승인 기록의 종료-시작 초 합계. 한 운행 중 정차 시간도 포함합니다.
- `previousMonthEnd`, `currentMonthEnd`: 해당 경계 시각 이하의 가장 최근 승인된 종료 계기판 후보. 각각 `boundaryAt`, `odometerKm`, `observedAt`, `tripId`, `status`를 제공합니다.
- `AT_BOUNDARY`는 정확히 경계 시각에서 관측한 값, `LAST_KNOWN_REQUIRES_REVIEW`는 그보다 과거의 마지막 값입니다. 이전 달보다 오래된 값일 수도 있으므로 관측 시각을 함께 확인해야 합니다.
- 승인된 근거가 없으면 `MISSING`, 기존 승인 자료에 측정 오류가 있으면 `INVALID_REQUIRES_REVIEW`이며 계기판은 null/빈 셀입니다. 0으로 채우지 않습니다.
- 월말 값 차이를 승인된 운행거리나 업무거리로 간주하지 않습니다. 월 귀속은 시작일 기준이므로 월을 가로지르는 운행은 특히 차이가 날 수 있습니다.
- `reviewNotes`에는 월말 기준 확인, 제외 기록 수, 수신 기록 없음 등을 표시합니다. 공백 검토도 필요합니다. 기록이 없다는 사실만으로 미운행이라 결론내리지 않습니다.

`unreviewedKnownKm`와 `unconfirmedKnownKm`는 다릅니다. 정상 상태 흐름에서는 전자는 미확인 거리와 승인 대기 거리의 합이고, 보완 요청 거리는 미확인 거리 안에 포함됩니다. 미완료 관측 거리는 이 합에 넣지 않습니다.
